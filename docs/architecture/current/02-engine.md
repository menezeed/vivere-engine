# Vivere Engine

## Objetivo
Transformar dados externos em dados confiáveis para publicação.

## Pipeline
Collector
→ Raw Data
→ Normalization
→ Venue Resolution
→ Category Classification
→ Recurrence Inference
→ Business Validation
→ Confidence Score
→ Human Review
→ Promotion

## Características
- Stateless
- Modular
- Idempotente
- Auditável
- Reprocessável

## Filosofia
A Engine nunca inventa dados.
Quando houver dúvida, encaminha para revisão humana.
